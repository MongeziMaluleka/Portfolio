Selected work

Two platforms I've built as a Platform Engineer at Old Mutual South Africa, where I work across backend and frontend on customer onboarding and API management.

KYC onboarding platform

Sole backend developer

  • Node.js
  • Express
  • PostgreSQL
  • Ping OIDC
  • JWT
  • Docker

I designed and built the platform's REST API from scratch. It serves both the customer onboarding app and the admin tools used by reviewers and support staff.

  • Single sign-on with Ping OIDC (Authorization Code Flow with PKCE), with customer accounts created automatically on first sign-in.
  • An end-to-end KYC journey for individual and business customers, with checks that flag what's missing before an application is submitted.
  • Admin tools for KYC reviewers and support agents, with role-based access control and a structured audit trail.
  • Security controls, a 253-test smoke suite and the full solution architecture documentation.

Pan-African API developer portal

Frontend developer

  • React
  • TypeScript
  • Material-UI
  • WSO2 API Manager

I built a custom frontend that turned the standard WSO2 developer portal into a branded marketplace, where developers find and subscribe to Old Mutual APIs across African markets.

  • A multi-country API catalogue with category, tag and country filters, covering banking, insurance, investments, payments and customer onboarding.
  • Responsive navigation and shareable links that open straight to a specific API or country.
  • A Get Started guide that takes developers from finding an API to going live.

Both are internal systems, so there's no public code or demo. I'm happy to walk through them in an interview.
